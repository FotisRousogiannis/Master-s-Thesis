# Πρώτη δοκιμή συστήματος (v0): υπολογιστής, σύνδεση με το Pi, υλικό

Σκοπός: να δούμε τι από το υπάρχον λογισμικό δουλεύει στην πράξη, **πριν** ο Φώτης αρχίσει τον δικό του κώδικα
(NOTES §9). Κάθε φάση στηρίζεται στην προηγούμενη· αν μια φάση αποτύχει, σταματάμε και τη διορθώνουμε.

## Τι ΔΕΝ μπορεί να δοκιμαστεί ακόμα
Η κίνηση του **πραγματικού** βραχίονα από το Arm Studio (μπάρες, MoveIt), το calibration ανά άρθρωση, το
«Μηδέν = τρέχουσα θέση», η τελευταία θέση στο ημερολόγιο και το πάνελ «Συσκευές» με πραγματικά δεδομένα. Όλα θέλουν
το node του Pi (`arm_pi_driver`, ADR-0021), που δεν υπάρχει ακόμα: `bringup.launch.py` δέχεται μόνο
`hardware:=mock|gazebo`. Στο υλικό φτάνουμε σήμερα μόνο μέσω του εργαλείου πάγκου `wrist_bench` (χωρίς ROS).

## Ασφάλεια (φάσεις 3–4)
- E-stop / διακόπτης τροφοδοσίας servo **στο χέρι**. Τα servo είναι συνεχούς περιστροφής: χωρίς παλμό **δεν κρατούν**,
  άρα με ρεύμα στα servo και έξοδο off, ένα link μπορεί να πέσει από το βάρος του. Ξεκίνα με τον βραχίονα σε στάση
  όπου δεν τον τραβά η βαρύτητα, ή στήριξέ τον.
- Τροφοδοσία servo **μόνο** στη φάση 4. Οι φάσεις 0–3 δεν κινούν τίποτα.

## Φάση 1 — Προετοιμασία του Pi
Στο Pi (οθόνη/πληκτρολόγιο ή SSH από το τωρινό δίκτυο):
```bash
cat /etc/os-release | head -2
```
```bash
sudo apt install -y i2c-tools python3-smbus2 python3-pytest git
```
```bash
git clone https://github.com/FotisRousogiannis/Master-s-Thesis.git && cd Master-s-Thesis && git checkout draft
```
```bash
python3 -m pytest software/tools/wrist_bench software/pi
```
```bash
ls -l /dev/i2c-1
```
Αν το `/dev/i2c-1` λείπει: `dtparam=i2c_arm=on` στο `/boot/firmware/config.txt` και επανεκκίνηση. Αν ο χρήστης δεν
έχει δικαίωμα σε αυτό (το SSH του Arm Studio τρέχει **χωρίς** sudo): `sudo usermod -aG i2c $USER` και ξανά σύνδεση.

## Φάση 3 — Υλικό, χωρίς κίνηση (servo χωρίς τροφοδοσία)
| # | Arm Studio → «Εργαλεία» | Αναμενόμενο (συνδεσμολογία ADR-0021) |
|---|---|---|
| 3.1 | Σάρωση I²C | `mux0: 0x40` · `mux1`…`mux6: 0x36` · `mux7: 0x36 0x48` |
| 3.2 | Encoders (5 s) | γωνία και `OK` μαγνήτη για κάθε encoder του `wrist_bench.json` |

Το `wrist_bench.json` περιγράφει ακόμα **μόνο τον καρπό** (encoders στα κανάλια 1/6/7, servo 8–11). Αν η σάρωση δείξει
τη νέα συνδεσμολογία, ενημερώνεται το `encoders` του αρχείου με τα 7 κανάλια **πριν** από το 3.2 (ρύθμιση, όχι κώδικας).

## Φάση 4 — Κίνηση, ένα κανάλι τη φορά
Στο Pi, από `software/tools/wrist_bench/` (το `jog` θέλει πληκτρολόγιο, άρα τερματικό SSH, όχι το Arm Studio).
Ένα κανάλι, μικρή ταχύτητα, σύντομα· τα όρια διαδρομής του πάγκου ισχύουν (30°):
```bash
python3 wrist_bench.py probe --channels 0 --offset 150 --duration 0.5
```
Επανάληψη για τα κανάλια 1…8. Για κάθε κανάλι: ποιος encoder (ποια άρθρωση) κινήθηκε και προς τα πού. Σε διαφορικό
(joint_1+2, joint_5+6) ένα servo μόνο του κινεί **και τις δύο** αρθρώσεις· είναι αναμενόμενο. Φορά και ταχύτητα με το
χέρι: `python3 wrist_bench.py jog --channel N` (W/S κίνηση, SPACE στάση, Q έξοδος).

Πάντα στο τέλος (και από το Arm Studio: «Εργαλεία» → «Όλες οι έξοδοι off»):
```bash
python3 wrist_bench.py stop
```
