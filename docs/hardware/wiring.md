# Συνδεσμολογία — πάγκος καρπού και αισθητήρες αφής

Τρέχουσα διάταξη δοκιμών (ADR-0012). Πηγή εξαρτημάτων: `Robotic-Arm/docs/BOM.md`.

## 1. Τροφοδοσία

```
Τροφοδοτικό 22 V ──┬── buck 5.1 V ──► Raspberry Pi
                   └── buck 7.4 V ──┬──► PCA9685 V+ (κλέμα)  → servo
                                    └── buck 3.3 V ──► VCC λογικής: TCA9548A, PCA9685, AS5600, ADS1115
Όλα τα GND κοινά (μη απομονωμένα buck). GND του Pi απευθείας στο GND του TCA9548A.
```

## 2. Δίαυλος I²C

| Συσκευή | Διεύθυνση | Σύνδεση | Ρόλος |
|---|---|---|---|
| TCA9548A | 0x70 | Pi pin 3 (SDA), pin 5 (SCL), pin 6 (GND) | mux I²C |
| PCA9685 | 0x40 | mux κανάλι **0** | οδηγός servo |
| AS5600 | 0x36 | mux κανάλια **1, 6, 7** | encoders καρπού |
| ADS1115 | 0x48 | mux κανάλι **2** (προτεινόμενο) | ADC αισθητήρων αφής |

## 3. Αισθητήρες αφής: ADS1115 + 2 × FSR402

### ADS1115
| Pin ADS1115 | Σύνδεση | Σημείωση |
|---|---|---|
| VDD | **3.3 V** (buck 3.3 V) | καθορίζει και το μέγιστο σήμα εισόδου (0–3.3 V) |
| GND | GND | κοινό |
| SCL | TCA9548A **SC2** | |
| SDA | TCA9548A **SD2** | |
| ADDR | **GND** | → διεύθυνση 0x48 |
| ALRT | ασύνδετο | δεν χρησιμοποιείται |
| A0 | FSR δάχτυλο 1 (διαιρέτης τάσης) | |
| A1 | FSR δάχτυλο 2 (διαιρέτης τάσης) | |
| A2, A3 | GND | αχρησιμοποίητες είσοδοι: στη γείωση για χαμηλό θόρυβο |

Πυκνωτής **100 nF** ανάμεσα σε VDD και GND, όσο πιο κοντά στο ADS1115.

### Διαιρέτης τάσης για κάθε FSR402
```
3.3 V ───[ FSR402 ]───┬──────────► A0  (ή A1 για το δεύτερο δάχτυλο)
                      │
                   [ R = 10 kΩ ]   (+ προαιρετικά 100 nF παράλληλα, φίλτρο θορύβου)
                      │
GND ──────────────────┘
```
`V_A0 = 3.3 V · R / (R + R_FSR)`

| Κατάσταση | R_FSR (ενδεικτικά) | V_A0 με R = 10 kΩ |
|---|---|---|
| χωρίς επαφή | > 1 MΩ | ≈ 0 V |
| ελαφριά επαφή | ~100 kΩ | ≈ 0.3 V |
| σταθερή λαβή | ~10 kΩ | ≈ 1.65 V |
| ισχυρή πίεση | ~1 kΩ | ≈ 3.0 V |

- **R = 10 kΩ**: ισορροπία ευαισθησίας και εύρους. Μεγαλύτερη R (π.χ. 47 kΩ) → πιο ευαίσθητο
  σε ελαφριά επαφή αλλά κορεσμός νωρίτερα· μικρότερη (3.3 kΩ) → μεγαλύτερο εύρος δύναμης.
- Ρύθμιση ADS1115: single-ended, PGA ±4.096 V, 128 SPS.
- Η τάση σε καμία είσοδο δεν πρέπει να ξεπερνά το VDD (3.3 V) — ο διαιρέτης από τα 3.3 V το εξασφαλίζει.

### Μηχανικά
- Το «ουράκι» του FSR402 είναι εύθραυστο: **όχι κόλληση** απευθείας στα pins (λιώνει το πλαστικό)·
  χρήση connector τύπου clincher ή female header, και ανακούφιση τάσης (strain relief) στο καλώδιο.
- Η ενεργή επιφάνεια πρέπει να πιέζεται **ομοιόμορφα**: ένα λεπτό άκαμπτο πλακίδιο ή μαξιλαράκι TPU
  πάνω από το FSR βελτιώνει την επαναληψιμότητα.
- Τα καλώδια περνούν από την κινούμενη αρπάγη: εύκαμπτο καλώδιο και περιθώριο κίνησης.

## 4. Για το PCB (σημειώσεις)
- ADS1115 και διαιρέτες FSR **στο PCB του καρπού**, κοντά στην αρπάγη (μικρά αναλογικά καλώδια).
- Πρόταση: αισθητήρας ρεύματος INA219 στη γραμμή 7.4 V (βλ. `docs/testing/wrist_bench.md`).
