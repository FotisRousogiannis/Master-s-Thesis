# Προσομοίωση αναλογικών κυκλωμάτων (SPICE)

Έλεγχος με **ngspice** των κομματιών της πλακέτας που είναι αναλογικά και δεν έχουν δοκιμαστεί στον πάγκο.
Το ψηφιακό κομμάτι (PCA9685, TCA9548A, ADS1115, AS5600 στο I2C) δεν προσομοιώνεται: είναι τα ίδια chips με
το bench rig, που ήδη λειτουργεί (`docs/testing/wrist_bench.md`).

```bash
sudo apt install ngspice
python3 hardware/pcb/segment_board/sim/run_sims.py
```

Τα netlists γράφονται στο `cir/`, τα γραφήματα και η σύνοψη στο `results/`. Οι τιμές είναι ίδιες με το
`gen/build.py`. Τα μοντέλα (SS34, LED, LM339) είναι γενικές προσεγγίσεις: ελέγχουμε σημεία λειτουργίας και
περιθώρια, όχι ακριβείς καμπύλες. Το LM339 μοντελοποιείται ως ιδανικός συγκριτής open collector με
offset εισόδου ±5 mV (μέγιστο datasheet).

## Αποτελέσματα (2026-11-08)

| Κύκλωμα | Αποτέλεσμα |
|---|---|
| Αφή: ηρεμία 17 kΩ | 0.94 V (ADS1115 ±4.096 V → κωδικός ~7540) |
| Αφή: πίεση 2 kΩ | 2.55 V (κωδικός ~20400), εύρος 1.6 V |
| Αφή: LED σύνδεσης | ανάβει για αισθητήρα < 68 kΩ (περιθώριο ×4 από τα 17 kΩ)· χωρίς αισθητήρα 0 V → σβηστό |
| Αφή: απόκριση φίλτρου 100 nF | 0.4 ms (ADS1115 στα 128 SPS = 7.8 ms/δείγμα) |
| Encoder: LED σύνδεσης | ανάβει στα 2.8–3.8 mA· AS5600 ~6.5 mA → περιθώριο ×1.7 |
| Encoder: ανύψωση γείωσης | 65 mV, αμελητέα για το I2C |
| Servo: LED σύνδεσης | ανάβει στα 1.1–3.2 mA → **το ρεύμα ηρεμίας του servo πρέπει να είναι > 3.2 mA** (TBD, μέτρηση) |
| Servo: ανύψωση γείωσης | 315 mV στα 0.4 A, 352 mV στα 0.8 A (το SS34 περιορίζει· χωρίς αυτό 3.76 V) |
| Servo: σήμα PWM | 2.95 V ως προς τη γείωση του servo στα 0.8 A — αρκετό |
| Servo: ισχύς | αντίσταση 26 mW, SS34 280 mW στα 0.8 A — εντός ορίων |
| LED σύνδεσης (1 kΩ από 3.3 V) | AlInGaP κιτρινοπράσινο 1.3 mA, InGaN πράσινο 0.7 mA → **επιλογή LED χαμηλής Vf** |

Γραφήματα: `results/touch.png`, `results/encoder_detect.png`, `results/servo_detect.png`.

## Τι δεν καλύπτει
- eFuses (TPS259827/TPS259472A), buck AP63203: οι TI/Diodes δίνουν μοντέλα PSpice/SIMPLIS που δεν τρέχουν
  αξιόπιστα στο ngspice· ακολουθούμε τα κυκλώματα αναφοράς των datasheet.
- ESP32, RS-485, Pi: ψηφιακά, ελέγχονται με το ERC και με δοκιμή στην πλακέτα.
