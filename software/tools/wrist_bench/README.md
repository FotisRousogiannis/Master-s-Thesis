# wrist_bench — πάγκος δοκιμών του καρπού (Raspberry Pi)

Εργαλείο Python για τις δοκιμές T0–T5 του καρπού χωρίς ROS/ESP32 (ADR-0012).
Πρωτόκολλο και αποτελέσματα: [`docs/testing/wrist_bench.md`](../../../docs/testing/wrist_bench.md).

```
Raspberry Pi ── I²C ──┬── PCA9685 (0x40) ── servo ×4
                      └── TCA9548A (0x70) ── AS5600 ×3 (0x36, ένα ανά κανάλι)
```

## `teleop.py`: μενού για τον πάγκο (σάρωση, μαγνήτες, κανάλια, διαφορικό)
Μεταφορά του `servo_diff_keyboard.py` του repo `Robotic-Arm` (commit `140b76d`), που κινούσε τη βάση, πάνω στους
drivers αυτού του φακέλου: ο PCA9685 και οι AS5600 βρίσκονται μέσω του TCA9548A, χωρίς `i2cset` και χωρίς venv.
```bash
python3 teleop.py
```
```
[1] Σάρωση I²C               ποιες συσκευές απαντούν σε κάθε κανάλι του TCA (PCA9685, AS5600, ADS1115)
[2] Μαγνήτες encoders        γωνία, κατάσταση μαγνήτη, AGC για κάθε AS5600 (5 αναγνώσεις)
[3] Επιλογή καναλιών         μοτέρ A/B (κανάλια PCA9685), ανεστραμμένο B, ποιοι encoders (κανάλια TCA)
[4] Κίνηση διαφορικού        κράτα W/S pitch (μοτέρ μαζί), A/D roll (αντίθετα), +/- ταχύτητα, SPACE στάση, Q μενού
[5] Έξοδοι off
```
Από το παλιό εργαλείο: ταχύτητα ως κλάσμα 0–1 (αρχή 0.4, βήμα 0.1), ίδια αντιστοίχιση σε παλμό, B ανεστραμμένο.
Αλλαγές: το πρώτο πάτημα κρατά 0.6 s (η επανάληψη του τερματικού αρχίζει μετά από ~0.5 s· με 0.25 s κάθε πάτημα
έκανε ξεκίνα-σταμάτα-ξεκίνα), οι παλμοί μένουν μέσα στο `max_offset_us`, οι έξοδοι σβήνουν στο τέλος, οι encoders
φαίνονται ζωντανά (όριο διαδρομής μόνο σε όσους έχουν μαγνήτη `OK`), προαιρετική καταγραφή CSV.
Κατευθείαν με κανάλια: `python3 teleop.py --a 0 --b 1 --enc 2,4`.

## Εντολές
| Εντολή | Κίνηση | Περιγραφή |
|---|---|---|
| `scan` | ❌ | συσκευές I²C στο κύριο bus και σε κάθε κανάλι του mux |
| `enc [--duration S] [--csv F]` | ❌ | ροή γωνιών και κατάστασης μαγνήτη των encoders |
| `pwm SERVO OFFSET_US [--duration S]` | ✅ | ένα servo με απόκλιση από το νεκρό σημείο |
| `diff PITCH_US ROLL_US [--duration S]` | ✅ | διαφορικό: A = p + r, B = sign·(p − r) |
| `deadband SERVO ENCODER` | ✅ | σάρωση παλμών, μέτρηση ταχύτητας → νεκρή ζώνη |
| `probe [--channels 0-15]` | ✅ | σύντομος παλμός σε κάθε κανάλι → ποιος encoder κινείται |
| `jog SERVO` ή `jog --channel N` [`--no-encoders`] | ✅ | χειροκίνητος έλεγχος με πληκτρολόγιο: **κράτα W/S** για κίνηση +/−, **A/D** πιο αργά/γρήγορα, SPACE στάση, Q έξοδος· ζωντανή ένδειξη encoders |
| `diffjog PAIR` [`--no-encoders`] [`--csv F`] | ✅ | διαφορικό ζεύγος (`base` ή `wrist`) με πληκτρολόγιο: **κράτα W/S** pitch (μοτέρ μαζί), **κράτα A/D** roll (μοτέρ αντίθετα), **+/−** ταχύτητα, SPACE στάση, Q έξοδος· ζωντανή ένδειξη των encoders του ζεύγους |
| `stop` | — | όλες οι έξοδοι off |

## Ασφάλεια (από `wrist_bench.json` → `safety`)
- `pulse_min_us` / `pulse_max_us` (στο `pca`): απόλυτα όρια παλμού από την προδιαγραφή του servo (500–2500 µs)· δεν ξεπερνιούνται ποτέ.
- `max_offset_us`: μέγιστη απόκλιση από το νεκρό σημείο (±900 µs = πλήρης ταχύτητα).
- `jog_start_offset_us` / `jog_step_us`: αρχική ταχύτητα και βήμα στο `jog` (300 / 90 µs ≈ 30% / 10%, όπως το παλιό εργαλείο).
- `diffjog_start_offset_us` / `diffjog_step_us`: αρχική ταχύτητα και βήμα στο `diffjog` (150 / 30 µs): πιο αργά, γιατί η βάση κουβαλά όλο τον βραχίονα.
- `max_duration_s`: μέγιστη διάρκεια κίνησης (3 s).
- `max_travel_deg`: διακοπή αν κάποιος encoder μετακινηθεί περισσότερο (30°).
- `jog_max_travel_deg`: στο `jog`, διακοπή αν κάποιος encoder απομακρυνθεί περισσότερο από την αρχική θέση (90°).
- Στο `jog` το servo κινείται **μόνο όσο φτάνουν συνεχώς W/S** (auto-repeat)· αλλιώς σταματά σε ~0.15 s.
- Κάθε κίνηση τελειώνει **πάντα** με όλες τις εξόδους off (και σε Ctrl+C ή σφάλμα).

## Διαφορικά (`differentials` στο `wrist_bench.json`)
Δύο μοτέρ κινούν μαζί δύο αρθρώσεις: `A = p + r`, `B = b_sign · (p − r)`. Ορισμένα ζεύγη:

| Ζεύγος | Μοτέρ (κανάλια PCA9685) | `b_sign` | Encoders για όριο διαδρομής | Πηγή |
|---|---|---|---|---|
| `base` | `base_a` (0), `base_b` (1) | −1 (B κατοπτρικό) | `enc_ch2` (mux 2), `enc_ch4` (mux 4)· όριο μόνο σε όσους έχουν μαγνήτη `OK` στην αρχή | `Robotic-Arm` `arm_calibration.json` (commit `140b76d`) |
| `wrist` | `diff_a` (9), `diff_b` (10) | −1 | — | όπως η εντολή `diff` |

Ο PCA9685 είναι πίσω από το TCA9548A (κανάλι 0): το εργαλείο ανοίγει μόνο του το σωστό κανάλι πριν από κάθε
εντολή, και τα encoders του ζεύγους στο δικό τους. Όσο τρέχει, κανένα άλλο πρόγραμμα I²C.
```bash
python3 wrist_bench.py diffjog base --csv base.csv
```
- Ξεκινά με ±360 µs (= `--speed 0.4` του παλιού εργαλείου· τα 150 µs δεν κινούσαν τη βάση).
- Οι encoders του ζεύγους φαίνονται ζωντανά με την κατάσταση του μαγνήτη· όποιος δεν έχει `OK` στην αρχή φαίνεται,
  αλλά δεν χρησιμοποιείται για το όριο. Αν κάποιος σταματήσει να απαντά, η κίνηση σταματά.
- `--csv`: μία γραμμή ανά κύκλο (χρόνος, κατάσταση, παλμοί των δύο μοτέρ, γωνίες, διαδρομή), για ανάλυση της
  σύζευξης και του τζόγου.
