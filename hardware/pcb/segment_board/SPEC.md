# Πλακέτα τμήματος (segment board) — προδιαγραφή v1

Μία κοινή πλακέτα για **κάθε τμήμα** του βραχίονα (link 1, καρπός). Ίδιο PCB παντού·
διαφορετικά εξαρτήματα κουμπώνονται ανάλογα με τη θέση. Απόφαση: ADR-0013.
Κατάσταση: **προς έγκριση** — τίποτα δεν είναι οριστικό πριν από το σχηματικό.

## 1. Βασικές απαιτήσεις
| # | Απαίτηση |
|---|---|
| R1 | Διαστάσεις **≤ 100 × 100 mm**, 2 στρώσεις, οπές στερέωσης M3 στις γωνίες. |
| R2 | **ESP32-S3-DevKitC-1** σε υποδοχή (headers) — ο τοπικός ελεγκτής κάθε τμήματος. |
| R3 | **Υποδοχή HAT** για Raspberry Pi 4 (40-pin header στη θέση του προτύπου HAT + οπές M2.5 58 × 49 mm): το Pi μπαίνει/βγαίνει. |
| R4 | Υποδοχές για **όλα** τα εξαρτήματα, ανεξάρτητα από το αν χρησιμοποιούνται σε μια θέση. |
| R5 | Λειτουργία **ESP32 ως master I²C** (στόχος) ή **Pi ως master I²C** (σημερινός πάγκος, χωρίς ESP32), με jumpers. Ποτέ και οι δύο μαζί. |
| R6 | Σύνδεση **Pi ↔ ESP32** της ίδιας πλακέτας με UART μέσω jumpers, και **σύνδεση προς την άλλη πλακέτα** με σειριακό καλώδιο (UART, προαιρετικά RS-485). |
| R7 | Τροφοδοσία servo έως **~8 A** συνεχώς με ασφάλεια, δυνατότητα E-stop και μεγάλους πυκνωτές για τις αιχμές. |
| R8 | Εξαρτήματα κυρίως **modules** σε υποδοχές και διαμπερή (THT) — κόλληση με το χέρι. |

## 2. Μπλοκ διάγραμμα
```
 7.4 V servo ─► [ασφάλεια] ─► [E-STOP] ─► [πυκνωτές] ─┬─► PCA9685 V+ ─► servo 0–15
                                                      └─► INA219 (μέτρηση ρεύματος servo)
 5.1 V λογική ─► [ασφάλεια] ─┬─► ESP32 5V
                             ├─► HAT 5V (Pi, όταν υπάρχει)
                             └─► LDO/buck 3.3 V ─► VCC: PCA9685, TCA9548A, ADS1115, INA219, AS5600

          ESP32 SDA/SCL ──┐  jumper «I²C master»
          Pi GPIO2/3   ───┴──► κύριο bus I²C ─┬─ PCA9685 (0x40)
                                              ├─ ADS1115 (0x48)
                                              ├─ INA219  (0x44)
                                              └─ TCA9548A (0x70) ─► AS5600 ×6 (κανάλια 0–5),
                                                                     κανάλια 6–7: εφεδρικά
          ESP32 UART ◄── jumpers ──► Pi UART (GPIO14/15)
          ESP32 UART2 ◄────────────► connector «LINK» (UART / RS-485) προς την άλλη πλακέτα
```

## 3. Υποδοχές (connectors)
| Λειτουργία | Πλήθος | Τύπος (πρόταση) | Σημείωση |
|---|---|---|---|
| Servo | 16 | στο ίδιο το module PCA9685 | τα servo κουμπώνουν στα headers του module |
| AS5600 | 6 (+2 εφεδρικά) | JST-XH 4 pin (3V3, GND, SDA, SCL) | ένας ανά κανάλι του TCA9548A |
| Αισθητήρες αφής ZD10 | 2 | JST-XH 2 pin | διαιρέτης 6.8 kΩ πάνω στην πλακέτα (A0, A1) |
| Αναλογικές εφεδρικές | 2 | pin header | A2, A3 του ADS1115 |
| Τροφοδοσία servo 7.4 V | 1 | βιδωτή κλέμα 5.08 mm, ≥ 10 A | |
| Τροφοδοσία λογικής 5.1 V | 1 | βιδωτή κλέμα 5.08 mm | |
| E-STOP | 1 | κλέμα 2 pin σε σειρά με τα 7.4 V | jumper/γέφυρα όταν δεν συνδέεται κουμπί |
| LINK προς άλλη πλακέτα | 1 | JST-XH 4 pin (TX, RX, GND, + RS-485 προαιρετικά) | |
| Θύρα I²C επέκτασης | 1 | JST-SH 4 pin (Qwiic) | για μελλοντικούς αισθητήρες |

## 4. Jumpers
| Jumper | Θέσεις | Χρήση |
|---|---|---|
| JP_I2C | ESP32 / Pi | ποιος οδηγεί το κύριο bus I²C |
| JP_UART | ανοιχτό / κλειστό | σύνδεση UART Pi ↔ ESP32 της ίδιας πλακέτας |
| JP_ESTOP | γέφυρα | όταν δεν υπάρχει κουμπί E-stop |

## 5. Διευθύνσεις I²C (κάθε πλακέτα έχει δικό της bus)
| Συσκευή | Διεύθυνση | Ρύθμιση |
|---|---|---|
| PCA9685 | 0x40 | προεπιλογή |
| INA219 | **0x44** | pads A1 στο module (η 0x40 συγκρούεται με τον PCA9685) |
| ADS1115 | 0x48 | ADDR → GND |
| TCA9548A | 0x70 | προεπιλογή |
| AS5600 | 0x36 | πίσω από τον mux, ένας ανά κανάλι |

## 6. Χρήση ανά θέση
| | Link 1 | Καρπός |
|---|---|---|
| ESP32 | ✅ | ✅ |
| Raspberry Pi (HAT) | ✅ | — |
| Servo | αυτά του link 1 | αυτά του καρπού |
| AS5600 | αυτοί του link 1 | αυτοί του καρπού |
| ZD10 | — | ✅ 2 |
| LINK | προς καρπό | προς link 1 |

## 7. Ανοιχτά σημεία
- Ακριβή μοντέλα/διαστάσεις των modules (PCA9685, TCA9548A, ADS1115, INA219, 3.3 V ρυθμιστής) → φωτογραφίες.
- Αγορά ESP32-S3-DevKitC-1 (×2).
- Κατανομή 9 servo / 6 encoders ανάμεσα σε link 1 και καρπό.
- Τροφοδοσία Pi μέσω των 5V pins του HAT (παρακάμπτει την ασφάλεια του Pi) — απαιτεί ασφάλεια στην πλακέτα.
