# ADR-0011: Εξαγωγή CAD με δικό μας script για το Fusion 360

- **Κατάσταση:** Αποδεκτή
- **Ημερομηνία:** 2026-10-21

## Πλαίσιο
Το URDF πρέπει να προκύψει από το μοντέλο του Fusion 360 (γεωμετρία, θέσεις και
άξονες αρθρώσεων, όρια, μάζες/αδράνειες). Δοκιμάστηκε το add-in **ACDC4Robot**:
- Σε απλό τεστ (2 κουτιά) απέτυχε με **As-built Joint**
  (`geometryOrOriginTwo` → `InternalValidationError`) και πέτυχε με κανονικό Joint.
- Στον βραχίονα απέτυχε πρώτα στην εξαγωγή STL (`export_stl` →
  `InternalValidationError`) και στη συνέχεια το Fusion **κρασάρει** αμέσως μετά την
  επιλογή μορφής/προσομοιωτή — ακόμα και με μόνο `base_link` και `link_1` — χωρίς
  ένδειξη για την αιτία.
- Κατά την τεκμηρίωσή του (v1.1.1), η εξαγωγή URDF είναι «διαθέσιμη αλλά όχι
  επανελεγμένη»· πλήρως ελεγμένη είναι μόνο η MJCF (MuJoCo).

## Εναλλακτικές
1. **Συνέχιση με ACDC4Robot** — κλειστό ως προς τη διάγνωση: το crash δεν αφήνει ίχνος.
2. **fusion2urdf** (και forks για ROS 2) — παρόμοια λογική, ίδιος κίνδυνος.
3. **Χειροκίνητη μοντελοποίηση** από διαστάσεις — χάνεται η ακρίβεια του CAD.
4. **Δικό μας script** (`software/tools/fusion_export/`) που εξάγει δεδομένα σε JSON
   + STL, και **δικός μας generator** στο repo που παράγει το xacro.

## Απόφαση
**Επιλογή 4.** Το script:
- γράφει κάθε βήμα σε `export_log.txt` **πριν** το εκτελέσει (εντοπισμός crash),
- τρέχει σε στάδια αυξανόμενου κόστους (δομή → joints → μάζες → STL) με
  επιβεβαίωση πριν από τα ακριβά στάδια,
- απομονώνει κάθε σύνδεσμο/joint σε `try`: μια αποτυχία καταγράφεται και η εξαγωγή συνεχίζει,
- υπολογίζει μάζες με χαμηλή ακρίβεια και STL με χαμηλή ανάλυση,
- προειδοποιεί για μη υποστηριζόμενα στοιχεία (As-built joints, υπο-components,
  mesh bodies, σώματα με >2000 έδρες, όρια που δεν είναι ενεργά).

## Αιτιολόγηση
Πλήρης έλεγχος και διαγνωσιμότητα· ο κώδικας είναι μέρος της εργασίας, εκδίδεται
στο repo και προσαρμόζεται όταν αλλάζει το Fusion API· ο μετασχηματισμός σε URDF
γίνεται εκτός Fusion, σε κώδικα που ελέγχεται με tests.

## Συνέπειες
- Χρειάζεται generator JSON → xacro (μετατροπή μονάδων, θεώρημα παράλληλων αξόνων
  για αδράνειες ως προς το κέντρο μάζας, πλαίσια αρθρώσεων).
- Οι μάζες διορθώνονται με πραγματικές μετρήσεις (βλ. μελλοντικό ADR για `link_masses.yaml`).
- Οι κανόνες μοντελοποίησης (επίπεδη δομή, κανονικά joints, σειρά επιλογής
  παιδί → γονέας, ενεργά όρια) τεκμηριώνονται στο README του script.
