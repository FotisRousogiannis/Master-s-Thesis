# Αρχείο αποφάσεων αρχιτεκτονικής (ADR)

Κάθε σημαντική απόφαση σχεδιασμού καταγράφεται σε ξεχωριστό αρχείο
(Architecture Decision Record). Ένα ADR δεν διαγράφεται· αν μια απόφαση
αλλάξει, γράφεται νέο ADR που την **αντικαθιστά** και το παλιό σημειώνεται
ως «Αντικαταστάθηκε από ADR-XXXX».

## Κατάσταση
- **Προτεινόμενη** — υπό συζήτηση
- **Αποδεκτή** — ισχύει
- **Αντικαταστάθηκε** — δεν ισχύει πλέον (βλ. νεότερο ADR)

## Πρότυπο

```markdown
# ADR-XXXX: Τίτλος

- **Κατάσταση:** Προτεινόμενη | Αποδεκτή | Αντικαταστάθηκε από ADR-YYYY
- **Ημερομηνία:** YYYY-MM-DD

## Πλαίσιο
Ποιο πρόβλημα λύνουμε, ποιοι περιορισμοί ισχύουν.

## Εναλλακτικές
1. ... — υπέρ / κατά
2. ...

## Απόφαση
Τι επιλέξαμε.

## Αιτιολόγηση
Γιατί αυτό και όχι τα άλλα.

## Συνέπειες
Τι σημαίνει για το υπόλοιπο σύστημα· τι πρέπει να προσέξουμε.
```
