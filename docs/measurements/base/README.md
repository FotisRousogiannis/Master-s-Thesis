# Μετρήσεις: βάση (διαφορικό joint_1 + joint_2), Raspberry Pi bench

Εργαλείο: `software/tools/wrist_bench/teleop.py`, επιλογή [7] (κλειστός βρόχος, ένας PID ανά άξονα).
Calibration: `software/tools/wrist_bench/base_calibration.json` (pitch = mux 2, sign +1· roll = mux 1, sign −1·
όρια ±90°). Ο encoder του mux 1 είχε μαγνήτη `OK` (AGC 30), του mux 2 `TOO_WEAK` (AGC 128).
PID: kp 0.02, ki 0, kd 0, ταχύτητα 0.3–0.5, ανοχή 1°.

| Αρχείο | Ημερομηνία | Στόχος | Αποτέλεσμα |
|---|---|---|---|
| `test.csv` | 2026-11-14 | pitch 0 → 80°, roll 0 → 20° | σταμάτησε στο όριο χρόνου 20 s: pitch 78.6°, roll 18.8° |
| `test_0_0.csv` | 2026-11-14 | pitch 29° → 0°, roll 0° | ✅ έφτασε σε 8.0 s: pitch −0.9°, roll 0.7° |

Στήλες: `t_s`, και για κάθε άξονα `_target`, `_deg` (γωνία), `_cmd` (εντολή ταχύτητας −1…1)· `ch0_us`, `ch1_us`
(παλμοί των μοτέρ A και B, `off` = χωρίς παλμό). Ρυθμός βρόχου ~39 Hz.

## Τι δείχνουν
- **Ταχύτητα:** pitch ~4.4°/s με εντολή 0.5, ~3°/s με 0.3. Τα 80° θέλουν ~20 s.
- **Σύζευξη:** στο `test_0_0` το roll δεν κινήθηκε όσο το pitch πήγαινε 29° → 0° (0.00°/s).
- **Μετά τη στάση** ο άξονας συνεχίζει λίγο (~−3.6°/s για ~0.5 s, ~1–2°): τελείωσε στο −0.9° (μέσα στην ανοχή).
- **Σφάλμα μίξης:** με εντολή pitch 0.3 και roll 0.3 το μοτέρ B έμενε χωρίς παλμό (A = 0.6, B = 0) και το roll **δεν
  κινούνταν** (−0.08°/s): το ελεύθερο B γύριζε ανάποδα αντί να κινηθεί η άρθρωση. Διορθώθηκε: μοτέρ στο 0 ενώ το άλλο
  κινείται παίρνει νεκρό σημείο (1600 µs) και φρενάρει. Όριο χρόνου 20 → 60 s.
