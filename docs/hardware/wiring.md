# Συνδεσμολογία — πάγκος καρπού και αισθητήρες αφής

Τρέχουσα διάταξη δοκιμών (ADR-0012). Πηγή εξαρτημάτων: `Robotic-Arm/docs/BOM.md`.

## 1. Τροφοδοσία

```
Τροφοδοτικό 22 V ──┬── buck 5.1 V ──► Raspberry Pi
                   └── buck 7.4 V ──┬──► PCA9685 V+ (κλέμα)  → servo
                                    └── buck 3.3 V ──► VCC λογικής: TCA9548A, PCA9685, AS5600, ADS1115
Όλα τα GND κοινά (μη απομονωμένα buck). GND του Pi απευθείας στο GND του TCA9548A.
```

## 2. Δίαυλος I²C

| Συσκευή | Διεύθυνση | Σύνδεση | Ρόλος |
|---|---|---|---|
| TCA9548A | 0x70 | Pi pin 3 (SDA), pin 5 (SCL), pin 6 (GND) | mux I²C |
| PCA9685 | 0x40 | mux κανάλι **0** | οδηγός servo |
| AS5600 | 0x36 | mux κανάλια **1, 6, 7** | encoders καρπού |
| ADS1115 | 0x48 | mux κανάλι **2** (προτεινόμενο) | ADC αισθητήρων αφής |

## 3. Αισθητήρες αφής: ADS1115 + 2 × ZD10 (αισθητήρας πίεσης λεπτού φιλμ)

Σημείωση: το `BOM.md` αναφέρει FSR402· τα διαθέσιμα αισθητήρια είναι **ZD10** (ίδια αρχή:
η αντίσταση μειώνεται με τη δύναμη, για μικρότερες δυνάμεις).

### ADS1115
| Pin ADS1115 | Σύνδεση | Σημείωση |
|---|---|---|
| VDD | **3.3 V** (buck 3.3 V) | καθορίζει και το μέγιστο σήμα εισόδου (0–3.3 V) |
| GND | GND | κοινό |
| SCL | TCA9548A **SC2** | |
| SDA | TCA9548A **SD2** | |
| ADDR | **GND** | → διεύθυνση 0x48 |
| ALRT | ασύνδετο | |
| A0 | ZD10 δάχτυλο 1 (διαιρέτης τάσης) | |
| A1 | ZD10 δάχτυλο 2 (διαιρέτης τάσης) | |
| A2, A3 | GND | αχρησιμοποίητες είσοδοι |

Πυκνωτής **100 nF** ανάμεσα σε VDD και GND, κοντά στο ADS1115.

### Διαιρέτης τάσης για κάθε ZD10
```
3.3 V ───[ ZD10 ]───┬──────────► A0  (A1 για το δεύτερο δάχτυλο)
                    │
                 [ R = 6.8 kΩ ]   (+ προαιρετικά 100 nF παράλληλα, φίλτρο θορύβου)
                    │
GND ────────────────┘
```
`V_A0 = 3.3 V · R / (R + R_ZD10)` — η τάση **αυξάνεται** με τη δύναμη.

- **Επιλογή R:** R ≈ √(R_χωρίς πίεση · R_με πίεση), στην πλησιέστερη πρότυπη τιμή.
  Μέτρηση 2026-11-05 (πολύμετρο): ZD10 ≈ **16–17 kΩ** χωρίς πίεση, ≈ **2 kΩ** με πίεση →
  √(16k · 2k) ≈ 5.7 kΩ → πρότυπη τιμή 5.6 kΩ· **τοποθετήθηκε αντίσταση 6.8 kΩ** (πρότυπη τιμή, επίσης εντός του βέλτιστου εύρους).
- Αναμενόμενη τάση στο A1 με R = 6.8 kΩ (ZD10 17 kΩ → 2 kΩ): **≈ 0.94 V** χωρίς πίεση, **≈ 2.55 V** με πίεση
  (με 47 kΩ θα ήταν 2.46 → 3.17 V, δηλαδή μισό εύρος μέτρησης).
- Χωρίς την R η είσοδος του ADC δεν τραβά ρεύμα: δεν πέφτει τάση στον αισθητήρα και το A1
  δείχνει πάντα 3.3 V. Η R δίνει τη διαδρομή ρεύματος (όπως το ρεύμα του πολυμέτρου σε Ω)
  και περιορίζει το ρεύμα σε ≤ 3.3 V / 6.8 kΩ ≈ 0.49 mA ακόμα και αν ο αισθητήρας βραχυκυκλώσει.
- **Επαλήθευση 2026-11-06 (πολύμετρο, A0–GND):** μέγιστη πίεση → **2.5 V** (υπολογισμός με 6.8 kΩ: 2.55 V). ✅
- Ρύθμιση ADS1115: single-ended, PGA ±4.096 V, 128 SPS.
- Καμία είσοδος πάνω από VDD (3.3 V): ο διαιρέτης από τα 3.3 V το εξασφαλίζει.

### Μηχανικά
- **Όχι κόλληση** απευθείας στους ακροδέκτες του φιλμ· connector (clincher / female header)
  και ανακούφιση τάσης στο καλώδιο.
- Λεπτό άκαμπτο πλακίδιο ή μαξιλαράκι TPU πάνω από την ενεργή επιφάνεια για ομοιόμορφη πίεση.
- Εύκαμπτο καλώδιο με περιθώριο κίνησης μέσα από την αρπάγη.

## 4. Για το PCB (σημειώσεις)
- ADS1115 και διαιρέτες ZD10 **στο PCB του καρπού**, κοντά στην αρπάγη (μικρά αναλογικά καλώδια).
- Πρόταση: αισθητήρας ρεύματος INA219 στη γραμμή 7.4 V (βλ. `docs/testing/wrist_bench.md`).
