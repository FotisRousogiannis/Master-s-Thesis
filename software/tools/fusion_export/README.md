# fusion_export — εξαγωγή του βραχίονα από το Fusion 360

Script για το Fusion 360 που εξάγει όσα χρειάζονται για το URDF, χωρίς add-ins τρίτων.
Αιτιολόγηση: ADR-0011.

## Εγκατάσταση (μία φορά)
1. `git pull` στο repo στα Windows (branch `draft`).
2. Fusion → **Utilities → Add-Ins → Scripts and Add-Ins** → καρτέλα **Scripts** → **+**
   (ή «Script or add-in from device») → επίλεξε τον φάκελο
   `software/tools/fusion_export`.

## Εκτέλεση
1. Άνοιξε το **αντίγραφο** του σχεδίου, **Save**.
2. Scripts and Add-Ins → `fusion_export` → **Run**.
3. Επίλεξε φάκελο εξόδου με απλή διαδρομή (π.χ. `C:\arm_export`).
4. Το script εκτελεί τα στάδια με τη σειρά, από το φθηνότερο στο ακριβότερο:
   1. δομή (components, bodies, υλικά, ορατότητα),
   2. joints (τύπος, γονέας/παιδί, άξονας, όρια, θέση),
   3. *(ερώτηση)* μάζες / κέντρα μάζας / αδράνειες — χαμηλή ακρίβεια,
   4. *(ερώτηση)* STL ανά σύνδεσμο — χαμηλή ανάλυση.

## Έξοδος
| Αρχείο | Περιεχόμενο |
|---|---|
| `export_log.txt` | κάθε βήμα γράφεται **πριν** εκτελεστεί· αν το Fusion κρασάρει, η τελευταία γραμμή δείχνει πού |
| `arm_export.json` | συνδέσμους, joints, μάζες (μονάδες Fusion: cm, kg, kg·cm², rad), προειδοποιήσεις |
| `meshes/<link>.stl` | ένα STL ανά σύνδεσμο |

Αντιγράφεις τον φάκελο εξόδου στο `software/cad_export/` και κάνεις commit/push.

## Κανόνες μοντελοποίησης
- Κάθε σύνδεσμος = ένα component **απευθείας κάτω από τη ρίζα**, με solid bodies (όχι υπο-components, όχι mesh bodies).
- Joints **κανονικά** (όχι As-built): πρώτα επιλέγεται το **παιδί**, μετά ο **γονέας**.
- Revolute/Slider με **ενεργά και τα δύο όρια** (min και max).
- Ονόματα: λατινικά, αριθμοί, `_`, `-`.
