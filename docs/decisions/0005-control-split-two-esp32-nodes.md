# ADR-0005: Διαχωρισμός ελέγχου — 2 PCB / 2 ESP32 nodes, τοπικός βρόχος θέσης

- **Κατάσταση:** Αποδεκτή
- **Ημερομηνία:** 2026-10-20

## Πλαίσιο
- Τα servo QY3240MG είναι **συνεχούς περιστροφής**: το PWM ορίζει ταχύτητα,
  όχι θέση. Έλεγχος θέσης υπάρχει μόνο με κλειστό βρόχο στους encoders AS5600.
- Ο βραχίονας έχει **διαφορικούς μηχανισμούς** (βάση, καρπός): δύο κινητήρες
  κινούν από κοινού δύο αρθρώσεις (`A = pitch + roll`, `B = pitch − roll`).
- Σχεδιάζονται δύο PCB με ESP32: ένα στο **link 1** και ένα στο **wrist**.

## Εναλλακτικές
1. **Ένα node ανά άρθρωση (6 nodes)** — απορρίπτεται: οι δύο κινητήρες ενός
   διαφορικού ανήκουν και στις δύο αρθρώσεις, άρα κανένα node δεν μπορεί να
   τους οδηγήσει μόνο του· δύσκολος συγχρονισμός· περιττή κίνηση δικτύου.
2. **Ένα PCB / ένα ESP32 για όλο τον βραχίονα** — χωράει (PCA9685: 16
   κανάλια, TCA9548A: 8), αλλά απαιτεί I²C σε καλώδιο ~1 m μέσα από κινούμενες
   αρθρώσεις (αναξιόπιστο) και πολλά καλώδια προς τον καρπό· ένα σημείο αποτυχίας.
3. **Δύο PCB, ένα ESP32 node ανά PCB** — κάθε ESP32 «κατέχει» ξένες μεταξύ
   τους αρθρώσεις και κάνει τοπικά τον βρόχο θέσης και τη μίξη διαφορικού.
4. **Βρόχος θέσης στον υπολογιστή** (ESP32 μόνο ως I/O) — απορρίπτεται: η
   καθυστέρηση του δικτύου θα έμπαινε μέσα στον βρόχο ελέγχου.

## Απόφαση
**Επιλογή 3.**
- **ESP32 link 1:** αρθρώσεις του link 1 / βάσης (με το διαφορικό της βάσης).
- **ESP32 wrist:** αρθρώσεις του καρπού + αρπάγη (με το διαφορικό του καρπού).
- Κάθε ESP32 εκτελεί: ανάγνωση AS5600 → PID θέσης (~500 Hz) → μίξη διαφορικού →
  PWM μέσω PCA9685, όρια αρθρώσεων και **watchdog** (χωρίς εντολή για ~200 ms →
  κράτημα θέσης).
- Ο υπολογιστής βλέπει μόνο **λογικές αρθρώσεις** (joint_1 … joint_6)· τον
  συντονισμό όλων τους κάνει ένα node, το **ros2_control**.
- Τα δύο ESP32 τρέχουν **το ίδιο firmware** με διαφορετικό αρχείο ρυθμίσεων.

## Αιτιολόγηση
Ο κρίσιμος βρόχος τρέχει δίπλα στους αισθητήρες, χωρίς δίκτυο· η σύζευξη των
διαφορικών λύνεται εκεί όπου υπάρχουν και οι δύο κινητήρες· το I²C μένει
τοπικό· ελάχιστα καλώδια μέσα από τις αρθρώσεις· αρθρωτή επέκταση.

## Συνέπειες
- **Κανόνας σχεδίασης PCB:** οι δύο κινητήρες **και** οι δύο encoders ενός
  διαφορικού συνδέονται στο **ίδιο** ESP32. Κανένα διαφορικό δεν μοιράζεται σε δύο πλακέτες.
- Οι encoders AS5600 κάθε τμήματος βρίσκονται κοντά στο ESP32 του (I²C ≤ ~30 cm).
- Η ακριβής κατανομή αρθρώσεων ανά PCB επιβεβαιώνεται όταν ολοκληρωθούν τα PCB.
- Ο διαχωρισμός σε 2 ESP32 είναι αθέατος πάνω από το ros2_control.
